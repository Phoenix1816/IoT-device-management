# IoT Telemetry Dashboard

A real-time IoT telemetry monitoring dashboard built with **ASP.NET Core .NET 8** and **React**.

The project simulates IoT devices by retrieving real-time environmental data from the **Open-Meteo API**, processing it on the backend, storing telemetry data in **MySQL**, and delivering live updates to the React dashboard using **SignalR**.

---

## 🚀 Project Overview

IoT devices continuously generate telemetry data such as:

- Temperature
- Humidity
- Pressure
- Wind speed
- Device status
- Last seen time

This project provides a centralized dashboard for monitoring these devices and their telemetry data in real time.

Instead of using physical sensors, the system currently uses **Open-Meteo** as a real-world data source for telemetry simulation.

The architecture is designed so that the simulation layer can later be replaced with real IoT devices or another telemetry source.

---

## 🏗️ Architecture

The current data flow is:

Open-Meteo API
      │
      ▼
Telemetry Simulation Worker
      │
      ├──► MySQL Database
      │
      ▼
SignalR Hub
      │
      ▼
React Frontend
      │
      ▼
Real-Time Telemetry Dashboard


### Data Flow

1. The `TelemetrySimulationWorker` periodically requests weather data from Open-Meteo.
2. The worker retrieves the current temperature.
3. Active IoT devices are loaded from the database.
4. A telemetry record is generated for each active device.
5. Telemetry data is stored in MySQL.
6. The backend broadcasts the telemetry data through SignalR.
7. The React frontend receives the data instantly.
8. The dashboard updates device telemetry, charts and status information in real time.

# ⚡ Real-Time Communication

The project uses **ASP.NET Core SignalR** for real-time communication between the backend and frontend.

The telemetry worker sends data to the SignalR hub:

TelemetrySimulationWorker
          │
          ▼
     TelemetryHub
          │
          ▼
       React App


The frontend listens for the:

ReceiveTelemetry


event.

Example payload:

{
  "deviceId": 21,
  "metric": "Temperature",
  "value": 23.5,
  "unit": "°C",
  "timestamp": "2026-08-28T08:30:00Z",
  "threshold": 30,
  "lastSeen": "2026-08-28T08:30:00Z"
}

# 🌦️ Open-Meteo Integration

The system currently uses Open-Meteo as the telemetry source.

Example request:

https://api.open-meteo.com/v1/forecast


The worker requests current weather information and extracts:

temperature_2m


The retrieved temperature is then treated as telemetry generated by the simulated IoT devices.

This approach allows the system to demonstrate real-time telemetry processing without requiring physical IoT hardware.

# 💻 Installation

## Requirements

Make sure the following are installed:

* .NET 8 SDK
* Node.js
* npm
* MySQL

---

## 1. Clone the Repository

git clone https://github.com/YOUR_USERNAME/IoTTelemetryDashboard.git
cd IoTTelemetryDashboard

---

# 2. Configure MySQL

Create a MySQL database:

CREATE DATABASE iot_telemetry;

Update the connection string in:

Backend/appsettings.json

Example:

"ConnectionStrings": {
  "DefaultConnection": "Server=localhost;Port=3306;Database=iot_telemetry;User=root;Password="
}

---

# 3. Start the Backend

Navigate to the backend directory:

cd Backend

Restore dependencies:

dotnet restore

Run the application:

dotnet run

The backend will start the telemetry simulation worker automatically.

---

# 4. Start the Frontend

Open another terminal:

cd Frontend

Install dependencies:

npm install

Start the development server:

npm run dev

The React application will be available through the Vite development server.
